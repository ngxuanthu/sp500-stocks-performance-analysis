S&P 500 – Investment Performance & Risk Analysis

Python | Tableau | Financial Analytics

Project Overview

This project analyzes the historical performance and financial risk of S&P 500 stocks using Python and Tableau, focusing on returns, volatility, and sector trends.

Objectives:

* Evaluate annual stock performance and volatility.
* Compare performance across sectors and sub-industries.
* Explore the risk–return relationship and identify outliers.

Data & Methodology

Source: Kaggle – S&P 500 Historical Stock Data
Period: 2000–2026 (focus: 2019–2025)

Python (Pandas) was used for data preparation and financial calculations.

Key metrics:

* Daily Return: Percentage change in daily stock prices.
* Annual Return: Stock performance over a calendar year.
* Annualized Volatility: Standard deviation of daily returns × √252.
* Risk–Return: Comparison of stock returns and volatility.

Tableau Dashboard

The interactive dashboard includes annual returns, volatility, sector performance, a risk–return scatter plot, Top 20 stocks, and summary KPIs.

Key Insights

* 2022: Significant market downturn, with sharp declines in several major stocks.
* 2024: Stronger performance and recovery across many companies.
* Risk vs. Return: Higher volatility does not necessarily imply higher realized returns.
* Sector Analysis: Performance and risk vary significantly across sectors and individual stocks.

Tools & Skills
